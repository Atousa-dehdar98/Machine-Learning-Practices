# Machine Learning Practices

A collection of hands-on machine-learning projects implemented in Python and Jupyter Notebook. The repository covers supervised learning, evaluation, clustering, image segmentation, and an end-to-end classification workflow.

## Projects

| Folder | Focus |
| --- | --- |
| `Machine Learning Introduction` | Feature engineering and introductory classification with food-allergy data. |
| `Data Analysis with Supervised Machine Learning` | Data preparation, PCA, and supervised learning. |
| `Evaluation Metrics` | Logistic-regression evaluation with a confusion matrix and classification report. |
| `Hepatitis-C-Classification-and-Clustering` | Cleaning data, clustering, classification, and result comparison. |
| `Image Segmentation with K-Means` | Pixel-based image segmentation with K-Means clustering. |

Every project folder includes its own README with project-specific details and a PDF task brief where available.

## Requirements

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn pillow
```

Open a notebook with Jupyter and run it from top to bottom to reproduce the workflow.
