# Data Analysis with Supervised Machine Learning

This project demonstrates a supervised-learning workflow on a synthetically generated dataset containing 1,000 observations, five numerical features, a continuous target, and intentionally introduced missing values.

## Workflow

- Investigate the dataset structure and missingness.
- Impute missing numerical values with the mean.
- Standardize features with `StandardScaler`.
- Reduce the feature space from five dimensions to two principal components using PCA.
- Split the data into training and test sets with an 80/20 ratio.
- Train and evaluate supervised models on the prepared data.

## Files

- `Data Analysis with Supervised Machine Learning.ipynb` — complete analysis and modeling workflow.
- `Description of Data Analysis with Supervised Machine Learning practice.pdf` — project brief.

## Run

Install Jupyter, NumPy, Pandas, Matplotlib, and scikit-learn, then run the notebook from top to bottom.
