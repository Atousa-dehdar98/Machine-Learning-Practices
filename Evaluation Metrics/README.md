# Evaluation Metrics

This practice evaluates a Logistic Regression classifier on the Iris dataset and interprets its performance beyond a single accuracy score.

## What it covers

- Load and explore the Iris dataset from scikit-learn.
- Split the observations into training and test sets.
- Train a `LogisticRegression` classifier.
- Evaluate predictions using a confusion matrix and classification report.
- Interpret precision, recall, F1-score, accuracy, and common class confusions.

## Files

- `Evaluation Metrics Practice.ipynb` — model training, evaluation, and reflection.
- `Description of Evaluation Metrics practice.pdf` — task brief.

## Run

Install Jupyter and scikit-learn, then execute the notebook sequentially.
